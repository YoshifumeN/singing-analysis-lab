2. 波形＋音量包絡

横軸：時間（秒）　縦軸：相対振幅／相対音量。灰色＝瞬間的な音圧の波形、青＝20 ms窓で計算したRMS音量包絡。A/B/Cのいずれかを選んでからグラフをクリックすると、その地点を比較対象として登録します。

3. F0（基本周波数）

横軸：時間（秒）　縦軸：F0（Hz、対数表示）。青＝推定された基本周波数（おおむね声の音高）、赤＝現在の解析地点。簡易自己相関法で推定しています。

4. A / B / C の周波数スペクトル比較

横軸：周波数（Hz）　縦軸：各地点ごとに最大ピークを0 dBとした相対強度（dB）。A/B/Cを重ね描きします。選択地点を中心に短区間FFTを行い、表示上限は5 kHzです。このスペクトルのうち、F0・2F0・3F0…付近の山を抜き出したものが下の「5. 倍音構造」です。

5. 倍音構造（4のスペクトルから倍音だけを抽出）
成分ABC
音声を読み込んでA/B/Cの地点を指定してください。
表の意味
H1＝F0付近、H2＝2×F0付近、H3＝3×F0付近…のピークです。A/B/Cそれぞれについて、その地点の最大ピークを0 dBとして相対強度を表示します。
